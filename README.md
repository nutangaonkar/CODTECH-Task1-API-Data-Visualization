# CODTECH Internship – Task 1
## API Integration and Data Visualization

### Description
This project fetches weather forecast data from the OpenWeatherMap API and visualizes temperature trends using Python and Matplotlib.

### Technologies Used
- Python
- Requests library
- Matplotlib
- OpenWeatherMap API

### Output
The output is a line graph showing temperature vs date & time for the next forecast records.

### How to Run
1. Install dependencies:
   pip install requests matplotlib
2. Run the script:
   python weather_visualization.py
